# Research 评估契约

所有 Research 试用都必须满足以下最低契约：

1. 先记录官方来源、版本和运行前提。
2. 使用可清理的 Docker 容器或临时 worktree。
3. 在运行组件前准备基线、成功条件和独立检查。
4. 执行主流程，不把安装成功当作功能成功。
5. 保存命令、输入、日志、产物、改动文件、测试结果和清理命令。
6. 报告必须区分已验证、未验证、阻塞和判断。
7. 有视觉界面就保存真实截图，没有视觉界面就保存终端或 API 证据。
8. 不读取或提交密钥，不挂载无关主机目录。

## 最低报告结构

- 组件用途
- 官方能力和来源
- 环境与版本
- 安装和部署
- 主流程
- 独立验证
- 截图或可执行证据
- 核心价值
- 未证明部分
- 清理和复现
