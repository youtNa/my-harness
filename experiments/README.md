# Experiments

Each experiment must be disposable, reproducible, and reportable.

## Planned first experiment

`e001-local-agent-quality-loop`

Compare an implementation agent and an independent review layer on the same small repository and task set.

## Required artifacts

- task definition
- baseline test output
- tool versions
- agent configuration without secrets
- patch or pull request diff
- test and review output
- scorecard
- cleanup log
