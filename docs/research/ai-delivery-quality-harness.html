核心证据

Agyn 证明了协调、研究、实现和 Review 角色组成的多 Agent 团队可以工作，但不能证明多 Agent 在所有项目上更可靠。

SWE-EVO 显示长周期软件演化能力明显弱于短任务基准。

SpecGuardBench 说明测试和验证器本身也需要被独立评估。

当前决策

Test First

先用 20 个真实 AI 生成 PR 比较现有 CI、人工 Review 和独立验证，验证能否发现真实缺陷并减少人工复核时间。
