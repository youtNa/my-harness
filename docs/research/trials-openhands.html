OpenHands 本地 Docker 试用

2026-11-19 · 个人本地环境

结论

✅ 本地容器可启动，沙箱挂载可用。

⚠️ 未执行模型调用，因此不能证明代码生成质量。

实际验证

  • Docker 29.2.1
  • 镜像 ghcr.io/all-hands-ai/openhands:main
  • 镜像摘要 sha256:0dcd216f…
  • SQLite 迁移、MCP、Uvicorn 监听 3000 成功
  • 仅挂载实验目录，没有挂载 SSH 或云凭证

流程

📦 拉取镜像 → 🐳 启动容器 → 🔒 挂载实验目录 → 🧪 等待模型任务

边界

  • docker run ... --help 会被入口脚本当作应用命令，不能获得 CLI 帮助。
  • 宿主机端口访问受当前受限环境影响，容器日志确认服务已监听。
  • 没有模型 API Key，未伪造任务成功。

清理

docker rm -f my-harness-openhands
docker image rm ghcr.io/all-hands-ai/openhands:main
